# Agent 评估框架

## 功能介绍

Agent 评估框架是一个动态评估业务场景下最佳 Agent 实现方案的工具，支持以下核心功能：

1. **动态场景生成**：基于业务上下文自动生成评估脚本和配置文件
2. **模块化脚本加载**：框架专注于加载和执行外部脚本，实现解耦
3. **并行脚本执行**：使用线程池并发执行多个评估脚本，提高效率
4. **智能报告生成**：自动分析评估结果，提供数据驱动的推荐和改进建议
5. **多维度性能评估**：评估模型调用次数、执行时间、Token 使用等关键指标

## 技术架构

### 核心组件

1. **场景生成器** (`scripts/scenario_generator.py`)
   - 从业务上下文提取场景信息
   - 生成场景配置文件
   - 生成评估脚本

2. **脚本执行器** (`scripts/script_runner.py`)
   - 发现和加载评估脚本
   - 并行执行脚本
   - 收集执行结果

3. **报告生成器** (`scripts/generate_report.py`)
   - 分析评估结果
   - 生成详细评估报告
   - 提供推荐和改进建议

### 工作流程

1. **输入业务上下文**：描述业务场景、核心功能、性能要求和技术约束
2. **生成评估脚本**：场景生成器自动生成评估脚本和配置文件
3. **执行评估**：脚本执行器加载并执行评估脚本
4. **生成报告**：报告生成器分析结果并生成详细评估报告
5. **查看推荐**：根据评估结果选择最佳 Agent 实现方案

## 使用方法

### 1. 生成评估场景

**从业务上下文生成**：

```bash
python scripts/scenario_generator.py --context "业务场景：电商客服智能助手\n核心功能：1. 订单查询 2. 产品推荐 3. 问题解决\n性能要求：响应时间快，稳定运行\n技术约束：使用标准框架"
```

**从参数生成**：

```bash
python scripts/scenario_generator.py --name "ecommerce_customer_service" --functions "订单查询" "产品推荐" "问题解决" --performance "响应时间快" "稳定运行" --constraints "使用标准框架"
```

### 2. 执行评估

**执行所有脚本**：

```bash
python scripts/script_runner.py
```

**执行指定脚本**：

```bash
python scripts/script_runner.py --script ecommerce_customer_service_evaluator
```

**指定测试用例**：

```bash
python scripts/script_runner.py --test-cases test_cases.json
```

### 3. 生成报告

```bash
python scripts/generate_report.py --results combined_evaluation_results.json --output final_report.md
```

## 注意事项

1. **场景描述格式**：使用结构化的业务场景描述，包含业务场景、核心功能、性能要求和技术约束
2. **评估结果解读**：综合得分越低越好，综合考虑执行时间和模型调用次数
3. **并行执行**：根据系统资源调整 `--max-workers` 参数，避免资源竞争
4. **脚本命名规范**：评估脚本应遵循 `<场景名称>_evaluator.py` 的命名规范
5. **配置文件匹配**：配置文件应与脚本名称对应，遵循 `<场景名称>_config.json` 的命名规范

## 扩展能力

1. **自定义评估指标**：修改 `generate_report.py` 中的评分算法，添加自定义指标
2. **新增评估方案**：在评估脚本中添加新的 Agent 实现方案
3. **集成监控系统**：扩展报告生成器，集成监控系统，实现持续评估
4. **支持更多模型**：修改评估脚本，支持不同类型的模型和工具

## 故障排除

### 常见问题

1. **脚本执行失败**
   - 检查脚本语法是否正确
   - 确保配置文件存在且格式正确
   - 检查依赖项是否安装

2. **场景生成失败**
   - 检查业务上下文格式是否正确
   - 确保包含足够的场景信息
   - 查看错误日志获取详细信息

3. **报告生成失败**
   - 检查评估结果文件是否存在
   - 确保评估结果格式正确
   - 查看错误日志获取详细信息

### 日志和调试

所有组件都会在执行过程中输出详细的日志信息，包括：
- 场景生成过程
- 脚本执行状态
- 评估结果收集
- 报告生成进度

通过查看这些日志，可以快速定位和解决问题。
